# Task & Team Management System

A mini Task & Team Management System built with .NET 10, Clean Architecture, CQRS, JWT Authentication and more.

## Projects

- **TMS.Api** – Web API entry point
- **TMS.Application** – Business logic, CQRS, DTOs, Validation
- **TMS.Domain** – Entities and Enums
- **TMS.Infrastructure** – Database, Identity, Logging, External services
- **TMS.Tests** – Unit and Integration tests
